# Legal and verification to-do

Everything needing a lawyer or a fact-check is a bracketed marker in the site. Run `npm run placeholders:md` and open `docs/PLACEHOLDERS.md` for the live list with file and line. Groups:

- `[LEGAL REVIEW REQUIRED]`: privacy notice, terms, consent text, retention periods, data residency, evidence-preservation guidance, operating entity.
- `[VERIFY]`: contact email, response time, owner public name, referral contacts for each authority, availability of StopNCII and Take It Down in Sri Lanka, press contact, metric definitions.
- `[STAGE 3]`: functionality not yet built (questionnaire, uploads, bot check).
